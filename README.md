# M.Tech DUAT Exam Guide — Cyber / AI

A comprehensive interactive exam preparation guide for the DUAT07 M.Tech entrance exam (Cyber Security / AI specialization).

## What's Inside

- **Part A** — 50 General Aptitude MCQs (Verbal, Quantitative, Logical, Analytical)
- **Part B** — 60 Technical MCQs (C Programming, Data Structures, Algorithms, OS, DBMS, Networks, Maths, ML)
- **Part C** — Full Mock Test (timed, scored)
- **Part D** — C Programming Deep Dive
- **Part E** — Data Structures & Algorithms
- **Part F** — CS Core Subjects (OS, DBMS, Networks)
- **Part G** — Mathematics & ML for AI/Cyber
- **Part H** — Last-Day Revision Sheet

## Features

- Interactive MCQ practice with explanations
- Timed mock test with scoring
- Topic-wise filtering
- Difficulty indicators
- Last-minute revision cheatsheet

## Tech Stack

- React 18
- Vite
- Plain CSS

## Run Locally

```sh
git clone https://github.com/Chilling-Python/mtech-duat-exam-guide.git
cd mtech-duat-exam-guide
npm install
npm run dev
```

## Deploy

Auto-deploys to Netlify on every push to `main`.
